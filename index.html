📝 文字转语音 API (TTS)

将文本转换为语音音频文件

端点： POST /v1/audio/speech
Content-Type： application/json
JavaScript 调用示例 
// JavaScript 调用示例
const response = await fetch('https://your-worker.workers.dev/v1/audio/speech', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
    },
    body: JSON.stringify({
        input: "你好，这是一个测试",
        voice: "zh-CN-XiaoxiaoNeural",
        speed: 1.0,
        pitch: "0",
        style: "general"
    })
});  

const audioBlob = await response.blob();  

// 保存为文件
const url = URL.createObjectURL(audioBlob);
const a = document.createElement('a');
a.href = url;
a.download = 'speech.mp3';
a.click();
URL.revokeObjectURL(url);
cURL 调用示例 
curl -X POST "https://your-worker.workers.dev/v1/audio/speech" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "你好，这是一个测试",
    "voice": "zh-CN-XiaoxiaoNeural",
    "speed": 1.0,
    "pitch": "0",
    "style": "general"
  }' \
  --output speech.mp3

请求参数

参数 类型 必填 说明
input string 是 要转换的文本内容
voice string 是 语音 ID，如 zh-CN-XiaoxiaoNeural
speed number 否 语速，范围 0.5-2.0，默认 1.0
pitch string 否 音调，默认 "0"
style string 否 语音风格，如 general、cheerful、calm 等

🎤 语音转文字 API (STT)

将音频文件转换为文本内容

端点： POST /v1/audio/transcriptions
Content-Type： multipart/form-data
JavaScript 调用示例 
// JavaScript 调用示例
const formData = new FormData();
formData.append('file', audioFile); // 音频文件
formData.append('token', 'your-siliconflow-token'); // 可选，不提供则使用默认 token

const response = await fetch('https://your-worker.workers.dev/v1/audio/transcriptions', {
    method: 'POST',
    body: formData
});

const result = await response.json();
console.log(result.text); // 转录结果
cURL 调用示例 
curl -X POST "https://your-worker.workers.dev/v1/audio/transcriptions" \
  -F "file=@audio.mp3" \
  -F "token=your-siliconflow-token"

请求参数

参数 类型 必填 说明
file File 是 音频文件（支持 mp3、wav、m4a 等格式）
token string 否 API 令牌（如使用硅基流动 API），不提供则使用默认配置

响应示例

{
  "text": "你好，这是一个测试",
  "language": "zh-CN",
  "duration": 2.5
}

⚠️ 错误处理

HTTP 状态码 说明
400 请求参数错误
401 未授权/令牌无效
413 文件过大
429 请求过于频繁
500 服务器内部错误
