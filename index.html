📝 文字转语音 API (TTS)

使用浏览器原生 SpeechSynthesis API

JavaScript 调用示例 
// 检查浏览器支持
if ('speechSynthesis' in window) {
    // 创建语音片段
    const utterance = new SpeechSynthesisUtterance('你好，这是一个测试');
    
    // 配置参数
    utterance.lang = 'zh-CN';      // 语言
    utterance.rate = 1.0;          // 语速 (0.1-10)
    utterance.pitch = 1.0;         // 音调 (0-2)
    utterance.volume = 1.0;        // 音量 (0-1)
    
    // 获取可用语音列表
    const voices = window.speechSynthesis.getVoices();
    console.log(voices);
    
    // 播放语音
    window.speechSynthesis.speak(utterance);
    
    // 停止播放
    // window.speechSynthesis.cancel();
} else {
    console.error('当前浏览器不支持语音合成');
}

SpeechSynthesisUtterance 参数

属性 类型 说明
text string 要合成的文本内容
lang string 语言代码，如 zh-CN、en-US
rate number 语速，范围 0.1-10，默认 1.0
pitch number 音调，范围 0-2，默认 1.0
volume number 音量，范围 0-1，默认 1.0
voice SpeechSynthesisVoice 指定语音对象

🎤 语音转文字 API (STT)

使用浏览器原生 SpeechRecognition API

JavaScript 调用示例 
// 检查浏览器支持
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;

if (SpeechRecognition) {
    const recognition = new SpeechRecognition();
    
    // 配置参数
    recognition.lang = 'zh-CN';           // 识别语言
    recognition.continuous = false;       // 非连续识别
    recognition.interimResults = true;    // 显示临时结果
    
    // 开始识别
    recognition.start();
    
    // 监听结果
    recognition.onresult = (event) => {
        const transcript = event.results[0][0].transcript;
        console.log('识别结果:', transcript);
    };
    
    // 监听错误
    recognition.onerror = (event) => {
        console.error('识别错误:', event.error);
    };
    
    // 停止识别
    // recognition.stop();
} else {
    console.error('当前浏览器不支持语音识别');
}

SpeechRecognition 属性

属性 类型 说明
lang string 识别语言，如 zh-CN、en-US
continuous boolean 是否连续识别，默认 false
interimResults boolean 是否显示临时结果，默认 false
maxAlternatives number 最大返回结果数量，默认 1
